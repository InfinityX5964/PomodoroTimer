# PomodoroTimer - An app for focused work, timed breaks, and tracking your daily sessions.

A simple, minimal Pomodoro timer designed to help you stay focused and take breaks when you need them. Includes dedicated focus sessions, short and long breaks, session tracking, and a distraction-free interface to keep you on track.

### Instructions to build the app:
1. Install Node.js LTS from nodejs.org
2. Open a terminal in this folder
3. npm install
4. npm run start   (optional: test it)
5. npm run dist    (builds dist\Focus.exe, a single portable file)
